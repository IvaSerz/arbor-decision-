Arbor v0.1.1 — исправление macOS-пакета.

В версии 0.1.0 отсутствовала корректная подпись ресурсов приложения: codesign сообщал «code has no resources but signature indicates they must be present». Теперь пакет подписывается ad-hoc на macOS после упаковки.

Для каждого Mac-архива CI распаковывает ZIP, проверяет подпись и запускает настоящее приложение: интерфейс, редактирование и автосохранение, внешний WASM-плагин, генерация PDF.

- Windows x64: полностью распаковать архив и запустить Arbor.exe.
- Mac Apple Silicon: Arbor-macOS-arm64.zip → Arbor.app.
- Mac Intel: Arbor-macOS-x64.zip → Arbor.app.

macOS 13 или новее. Движок включён; установка библиотек и интернет не нужны.

Ad-hoc подпись обеспечивает целостность, но не подтверждает издателя. Developer ID и нотариализация Apple не настроены, поэтому Gatekeeper может потребовать явного разрешения пользователя. После попытки открыть приложение: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» (если эта возможность доступна и политика устройства допускает запуск). Проверка доверия Gatekeeper не считается пройденной.

Данные демонстрационные. Это ранний прототип; индивидуальные оценки экспертов, AHP, TOPSIS и полноценный API методов ещё не реализованы.
