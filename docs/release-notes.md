Первый прототип Arbor — офлайн-система поддержки решений.

Архивы содержат Electron: браузер, Node.js, Rust и отдельные библиотеки пользователю не нужны.

- Windows x64: полностью распаковать папку и запустить Arbor.exe.
- Mac Apple Silicon: архив Arbor-macOS-arm64.zip, открыть Arbor.app.
- Mac Intel: архив Arbor-macOS-x64.zip, открыть Arbor.app.

Сборки выполнены GitHub Actions на Windows/macOS. Подпись и нотариализация не настроены: Windows может предупредить об издателе, macOS — блокировать открытие. Интерактивная работа приложения на целевых ОС пока не проверена.

В прототипе: пять технологий обследования деревьев, редактирование оценок и весов, взвешенная сумма, анализ чувствительности, JSON-проекты, PDF и экспериментальный WASM-плагин. Данные учебные. Индивидуальные оценки экспертов, AHP, TOPSIS и полный API методов ещё не реализованы.

Контрольные суммы — SHA256SUMS.txt.
